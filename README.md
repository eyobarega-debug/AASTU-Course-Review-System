# 🎓 AASTU Course Review System

A C++ console-based course review system developed as a university project for **Addis Ababa Science and Technology University (AASTU)**.

The system allows students to interact with course information and submit course reviews through a simple command-line interface. It was developed to practice core C++ programming concepts, including functions, structures, arrays, file handling, and basic data management.

## 📌 Project Overview

The **AASTU Course Review System** is designed to provide a simple way for students to share their opinions and experiences about university courses.

The project focuses on applying fundamental programming concepts to a practical university-related problem.

### 🎯 Main Goals

* Allow students to review courses
* Store and manage course-related information
* Practice C++ programming fundamentals
* Apply file handling for persistent data
* Build a simple menu-driven application
* Improve problem-solving and programming skills

## 🚀 Getting Started

### Prerequisites

You need a C++ compiler installed on your computer.

Recommended:

* MinGW / MinGW-w64
* GCC
* Visual Studio
* VS Code with a C++ compiler

### 1. Clone the repository

```bash
git clone https://github.com/eyobarega-debug/AASTU-Course-Review-System.git
```

### 2. Enter the project directory

```bash
cd AASTU-Course-Review-System
```

### 3. Compile the program

Using g++:

```bash
g++ cpp_project.cpp -o course-review
```

### 4. Run the program

On Windows:

```bash
course-review.exe
```

Or:

```bash
./course-review
```
